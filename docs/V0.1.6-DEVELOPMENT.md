## Clipboard review #10985

Qt 6.12's `QQuickTextInput::q_canPasteChanged()` retrieves MIME text on
clipboard change. This receiver belongs to Qt, not Familiar's Rust backend.
Replace all three editable TextInputs with `SafeTextInput`, based on plain-text
TextEdit: Qt's `QQuickTextControl::canInsertFromMimeData()` checks `hasText()`
without retrieving the payload. Explicit paste is handled by the Rust helper
using `wl-paste`, with a 16 KiB total limit and a two-second total deadline.
This uses Omarchy's `wl-clipboard` dependency; if unavailable, paste fails closed
without invoking Qt's native clipboard read. Typing remains available.
Overflow, failure, lost focus and intervening edits discard the result.
Middle-click follows the same bounded clipboard path, not primary selection.

Source review: Qt qtdeclarative tag v6.12.0, `src/quick/items/`
`qquicktextinput.cpp`, `qquicktextedit.cpp`, `qquicktextcontrol.cpp`.
Tests cover endless/silent producers, errors, invalid UTF-8 and editor updates.
Still requires a live Qt 6.12 Wayland clipboard-owner test (including clipboard
changes without a paste gesture), IME, selection, Enter/Escape and focus checks.

## Official titlebars #74

Core #14482 merged on 11 October at
`14987189695a8ae1f2270262fdf77446fafb1ba3`; package #957 merged and builds from
`omacom/omarchy-hyprland-titlebars` v0.2.0. The previous statement that Core
integration is unmerged is superseded.

The desktop test baseline now pins v0.2.1 and its verified source checksum from
package [#964](https://github.com/omacom/omarchy-pkgs/pull/964), merged later on
11 October. It adds the retained-renderer regression: remove the configuration
without unloading the library, require no bars or reserved space, then restore
the configuration and verify the actual Familiar minimise control. Earlier
v0.2.0 CI results do not cover this change.

Familiar now uses that renderer for Mac/Windows/theme controls, including
minimise and explicit clicked-window targets. It keeps Core's floating-workspace
scope and replaces only the two default button declarations during Core's config
apply call. A guarded compatibility adapter checks the current contract and
restores the Lua API even on failure. It is not a published Core extension API.
No private renderer is loaded on the official path. Symbols use the stock font
renderer rather than Familiar's old custom Cairo icons.

Explicit migration preserves settings and requires logout/login for previous
private owners. Disable restores Core defaults. Reconciliation is transactional,
and stale teardown cannot reset newer controls. Official-host setup avoids
private downloads; guarded development install/rollback stays available. See
[titlebar migration](TITLEBAR-MIGRATION.md) for the exact contract, tests and
outstanding desktop acceptance. No package-channel change is made.
